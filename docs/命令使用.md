# 命令使用

Auto Torch 的命令以 `/autotorch` 开头。客户端命令只在本地执行；管理员命令只注册在服务端。

## 客户端命令

### 界面、帮助和状态

| 命令                           | 用途                          |
| ------------------------------ | ----------------------------- |
| `/autotorch`、`/autotorch gui` | 打开设置与选区面板            |
| `/autotorch help`              | 显示命令帮助                  |
| `/autotorch status`            | 显示功能开关、选区和任务状态  |
| `/autotorch config defaults`   | 恢复客户端默认配置并写回 TOML |

### 附近自动插火把

```text
/autotorch nearby on|off
/autotorch nearby threshold <1-16>
/autotorch nearby skylight on|off
```

`threshold` 设置触发插火把的光照阈值；`skylight` 控制判断时是否计入天空光。

### 光照显示

```text
/autotorch overlay on|off
/autotorch overlay range <1-64>
/autotorch overlay mode crosses|numbers
/autotorch overlay detect swamp_slime on|off
/autotorch overlay detect drowned on|off
```

### 选区

```text
/autotorch selection pos1 [here|target|<x> <y> <z>]
/autotorch selection pos2 [here|target|<x> <y> <z>]
/autotorch selection swap
/autotorch selection clear
/autotorch selection box <x1> <y1> <z1> <x2> <y2> <z2>
/autotorch selection sphere <cx> <cy> <cz> <radius>
/autotorch selection tool on|off
/autotorch selection wooden_axe on|off
```

不指定 `here`、`target` 或坐标时，`pos1`、`pos2` 使用准星指向的方块；`here` 使用玩家脚部坐标。`wooden_axe` 是 `tool` 的别名。

### 照明范围、排除区和任务

```text
/autotorch selection list
/autotorch zone list [编号]
/autotorch zone clear

/autotorch zone lighting set|load|clear
/autotorch zone exclusion add
/autotorch zone exclusion load|replace|remove <编号>
/autotorch zone exclusion clear

/autotorch task start|cancel|status
```

照明范围编号为 `0`，排除区从 `1` 开始编号。`set` 或 `add` 保存当前草稿；`load` 把已有区域载入草稿以便修改；`replace` 用当前草稿替换指定排除区。

`task start` 使用当前照明范围、排除区和默认任务参数。任务仍会经过服务端的区域大小、权限、火把数量和扫描预算校验。

## 管理员命令

管理员命令要求游戏管理员权限，只在服务端注册。专用服务器控制台可省略开头的 `/`，直接执行 `autotorch` 会显示帮助。

> fabric 端下述命令仅支持在服务器中使用，因为 fabric 的命令树会有冲突

```text
/autotorch serverconfig get <key>
/autotorch serverconfig set <key> <value>
/autotorch serverconfig defaults
```

区域自动插火把的服务端总开关：

```text
/autotorch serverconfig set lightingTask.enabled false
/autotorch serverconfig set lightingTask.enabled true
```

关闭后，客户端仍可编辑选区，但“开始任务”和“取消任务”按钮会变灰；服务端会拒绝新的任务，并在下一刻停止正在运行的区域自动插火把任务。

`get` 查询当前值，`set` 修改并立即生效，`defaults` 恢复全部服务端默认值。修改会自动写回 TOML，并把最新限制同步给在线玩家。布尔值使用 `true` 或 `false`，整数必须处于配置允许的范围内；输入 `<key>` 时可以使用命令补全。可用键名见README.md中的“服务端配置”部分。

例如：

```text
/autotorch serverconfig get limits.maxSphereRadius
/autotorch serverconfig set limits.maxSphereRadius 80
/autotorch serverconfig set gameplay.survivalConsumesTorches false
```

直接编辑 TOML 需要重启服务端后生效；通过命令修改则立即生效。
